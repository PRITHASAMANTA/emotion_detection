# Facial Emotion Recognition using OpenCV and DeepFace

This is a customized and improved version of a real-time facial emotion recognition project.  
Developed and modified by PRITHA SAMANTA

---

## 📌 Overview

This project captures live video from your webcam, detects faces, and predicts the emotion expressed on each face using the `deepface` library and OpenCV.  
The predicted emotion label is displayed on the video feed in real-time.

---

## 🔧 Features

- Real-time face detection using Haar Cascade Classifier
- Emotion prediction using DeepFace
- Lightweight and easy to understand
- Clean and modifiable Python code

---

## 📂 Files

- `emotion.py` – Main Python script for face detection and emotion recognition
- `haarcascade_frontalface_default.xml` – Pre-trained model for face detection
- `requirements.txt` – List of required Python libraries
